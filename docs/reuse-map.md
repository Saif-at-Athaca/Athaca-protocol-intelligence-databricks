# Reuse map: Protocol Intelligence → PI on Databricks POC (A01)

Source: `Athaca/Protocol-Intelligence-New-UI`, branch `release/v1-saved-runs-deploy` at `2ea6e35` (Oct 23). Paths are relative to `backend/app/` unless noted.

## Verdict key

| Verdict | Meaning |
|---|---|
| **Reuse** | Port as-is or with config / path changes; already meets the Developer Brief rules |
| **Adapt** | Keep the core logic; change plumbing (model endpoint, Delta instead of live API, UC function, provenance) |
| **Rebuild** | Breaks a Brief rule at its core, or Databricks provides it |
| **Not for POC** | Outside the POC scope; not ported |

## New builds: nothing to reuse

The Developer Brief scopes in pieces the existing code has no equivalent for. They are built new:

- **Decision record and change impact:** recording a decision against the evidence rows it used, and flagging it when a new AACT snapshot changes one of them. Target: `pi.outputs.decisions`, `decision_evidence` and `evidence_change_flags`, linked to evidence through `trial_field.field_id`.
- **Per-field provenance and reviewer status** (A02, for AC2); the existing code labels provenance per record, module or UI section. Designed in A02 (`docs/trial-model-schema.md`, separate PR): one row per field value with version history, reviews in their own table.

## Port plan

1. **A03 (Nov 4–5), port extraction:** take #1, #2, #3, #11. Swap the model client to the serving endpoint; add `min_age` / `max_age`; return page + verbatim quote for enrollment, masking, primary endpoint and age range; verify each quote against the page text in code; emit per-field provenance rows in the A02 shape; check against the VITAL expected values (A04), including the composite primary endpoint (R4).
2. **A06 (Nov 9–10), silver mapping:** reuse the AACT column mappings from #5 and the `LandscapeTrialRecord` field list from #8; add `interventions` and the AACT snapshot date.
3. **A07–A09, A11 (Nov 11–17):** build gold from `trial_field_current` (A07); build `build_cohort` fresh (#7); port `landscape/coverage.py`, `builders.py`, `stats.py` into `design_distribution` / `coverage_report` (#8); base `position_element` on the landscape anchors (#10).
4. **Not ported:** indication bridge (#6), legacy aggregates (#9), complexity score (#13), Scenario (#16), RWD (#17).
5. **Replaced by Databricks:** run record and LLM ledger (#14) by MLflow tracing and `pi.outputs`; auth and hosting (#18) by Databricks Apps with OAuth on behalf of the user.
